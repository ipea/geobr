## R↔Python argument-order parity across all 31 `read_*` functions

**Goal.** Make the argument order of every `read_*` identical in R and Python.

**Finding.** R was already internally consistent (31/31:
`<year|date>, <code_*>, [extras], simplified, output, showProgress, cache, verbose`).
Python held two competing orders — 10 readers matched R, 21 hoisted `verbose` ahead of
`output`. R was taken as canonical (CRAN-published, self-consistent); R was left
unchanged except where Python had a parameter R lacked.

**Changes.**
- Python: `verbose` moved to last in 19 readers; `read_municipality`'s
  `keep_areas_operacionais` moved after `verbose`; `read_capitals`'s `year` moved first.
- Python: `read_conservation_units` lost `code_state` (the data set has no state column,
  so the filter silently did nothing); `read_urban_area` now defaults `simplified=True`;
  `read_census_tract` now requires `code_tract`; `read_comparable_areas` gained
  `show_progress`/`cache` (accepted-and-unused, exactly as in R).
- R: `read_capitals()` gained `year = 2010`, previously hardcoded.

**Deliberately not changed.**
- `read_state(year = NULL)` in R is a broken default — the "NULL = latest year" branch in
  `select_year_input()` is commented out, so `read_state()` fails with
  "argument is of length zero". Python's `year` stays required rather than copying it.
  This is the one remaining default mismatch. **Open question for the maintainer:** restore
  the latest-year branch, or drop the `NULL` default?
- `read_census_tract`'s required `code_tract`: an earlier NEWS.md entry records this as a
  deliberate decision, so R was left alone and Python was aligned to it instead.

**Out-of-scope bug found and fixed** (surfaced while first reading the request as being
about *column* order): `read_health_region(geometry_level="micro"|"macro")` in Python
grouped by `code_muni6`, present in the 1991-2013 files, which split every health region
back into its municipalities and made the union aggregation a no-op for those years. R
avoided this only accidentally, via an unanchored `grepl`. Both sides now drop columns by
prefix. Verified in R: 1991 micro returns 438 rows.

**Verification.**
- `devtools::test('r-package')` → 323 pass, 0 fail, 1 skip (the documented baseline).
- `devtools::document('r-package')` clean; `man/read_capitals.Rd` regenerated.
- Three-way check (pinned table == R `args()` == Python AST) passes for all 31 readers.
- Docstring tokens match signatures in every Python reader.
- `py_compile` clean on 45 files. **Python test suite: SKIPPED — no local Python toolchain;**
  covered by `.github/workflows/Python-CMD-check.yaml`.
